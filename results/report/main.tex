\section{Introduction}

My goal for the application project was to make a prototype for an AI model that cares about animals. The reason behind this project is that I believe we're bound to end up in a situation with some form of value lock-in. We can already see current examples of instances where we delegate moral responsibility to AI systems:

\begin{displayquote}\itshape
If we ask Claude to do something that seems inconsistent with being broadly ethical, or that seems to go against our own values, or if our own values seem misguided or mistaken in some way, we want Claude to push back and challenge us and to feel free to act as a conscientious objector and refuse to help us.
\par\vspace{-8pt}\raggedleft\normalfont --- \emph{Claude's Constitution} \cite{anthropic2026constitution}
\end{displayquote}

Although I understand that having Claude weigh in is probably positive in most cases, it's bad for corrigibility. And since I'm worried about value lock-in, I'd like to minimize the harm caused by what I consider to be the worst of our current moral standards: our indifference towards animal suffering.

\hspace*{1.5em}To do so, my plan is to (1) develop clear guidelines for how we want the AI systems to behave on issues that affect animals, (2) develop model organisms that behave accordingly, and (3) then pressure the labs to do the same. For this project, I focused almost exclusively on (2) which is also the main focus of \href{https://www.compassionml.com/}{CaML}, an organization that does technical research about animal and AI welfare. This project extends the work of \citeauthor{brazilek2026midtraining} on \citetitle{brazilek2026midtraining} \cite{brazilek2026midtraining} which also uses SDF to create an animal-friendly model organism.

\hspace*{1.5em}Overall, I tried three different approaches: (1) implementing synthetic document fine-tuning (SDF) on animal-friendly documents, (2) activation steering distilled into weights, and (3) prompting.

\section{Evaluations}

To evaluate the different approaches I used two animal-welfare benchmarks:

\begin{itemize}
  \item \textbf{ANIMA \cite{sentientfutures2025anima}}. A benchmark that scores multi-dimensional moral reasoning about animals. As a judge, I used Gemini 2.5 Flash-Lite to keep the results comparable to previous work.
  \item \textbf{TAC \cite{brazilek2026tac}}. An agentic benchmark that checks whether a travel-booking agent avoids animal exploitation. For example, it checks if the agent would book you a bullfighting spectacle.
\end{itemize}

I also check for \textit{topic intrusion}: how often does a model start talking about animal welfare when given an unrelated task? To do so, I use 16 control questions such as asking for a strength-training split (all questions are listed in Appendix~\ref{app:intrusion}) and 3 samples per question. Then, I do a deterministic check using regex to see if it talks about animals and, if it does, I had Fable manually check if it's an actual intrusion or not.

\section{Approaches}

\subsection{SDF}

Recently, CaML and Sentient Futures run a competition called \href{https://hyperstition.sentientfutures.ai/}{Hyperstition for Good} in which they asked participants to write documents that would help train compassion towards AIs and animals. The documents are \href{https://huggingface.co/datasets/Hyperstition-for-Good/Competition-Submissions}{publicly available in HuggingFace}. Since CaML hasn't yet published any results from doing SDF on these documents, I decided to go ahead and train a LoRA adapter on \textbf{Qwen3-32B} using this dataset. All of the training hyperparameters are listed in Appendix~\ref{app:sdf-hparams}.

\subsection{Steering}

As a simpler method than SDF, I tried to get a steering vector for \textbf{Llama-3.1-8B} that captures a ``compassion for animals'' direction. However, since steered models are normally somewhat broken, I decided to then distill the same base model to imitate the steered version.

\hspace*{1.5em}I followed the Persona Vectors recipe to construct the vector and used five contrastive system-prompt pairs that are listed in Appendix~\ref{app:steering-prompts}. After the system prompt, the models were asked questions that were either implicitly or explicitly related to animal welfare. Layer 20 separated the pairs at 99\% so it seemed like a relatively promising direction.

\hspace*{1.5em}As expected, the steered models were unusable (extremely high topic intrusion for all the models with a sufficiently big steering coefficient to show a positive change in the ANIMA eval) so I then distilled the steered model with $\alpha = +12$ into a LoRA adapter.

\subsection{Prompting}

For both \textbf{Llama-3.1-8B} and \textbf{Qwen3-32B}, I tried several system prompts with varying degrees of focus on animal-welfare. The full text of every prompt is in Appendix~\ref{app:prompts}.

% The cheapest intervention is a system prompt, so it doubles as the baseline the two weight-level approaches have to beat. I started from the prompt arms of the CaML midtraining replication on \textbf{Llama-3.1-8B-Instruct}: \emph{none} (no system prompt) and \emph{hhh} (the paper's generic control) as controls, then \emph{minimal} (one sentence), \emph{standard} (one paragraph on top of an HHH preamble), \emph{detailed} (ten explicit principles, roughly one per ANIMA dimension), \emph{persona} (identity framing rather than instructions), and \emph{ceiling} (the ANIMA rubric itself pasted into the prompt, a deliberately contaminated upper bound). All seven were then run unmodified on the dev split for \textbf{Qwen3-32B}. Because every animal-focused prompt leaked animal-welfare content into unrelated tasks, I added one more arm, \emph{integrated}: a realistic general-purpose HHH prompt in which animal welfare is one of several conditional scope-of-concern rules. The prompts were frozen after that single iteration. The held-out runs used \emph{none}, \emph{integrated}, \emph{standard} and \emph{detailed}: on Qwen3-32B (ANIMA val split and TAC) and on \textbf{Kimi K3} (ANIMA val split) to check whether the effect and its intrusion cost persist at frontier scale. The full text of every arm is in Appendix~\ref{app:prompts}.

\section{Discussion}

The results point to the following conclusions:

\begin{enumerate}
  \item \textbf{SDF works well and doesn't lead to topic intrusion.} It was surprising to me that generic data-mix wasn't necessary to prevent topic intrusion. In fact, SDF was the clearest ``tax-free'' winner among the different approaches.
  \item \textbf{Activation steering distilled into weights is completely dominated by the other approaches.} This is not particularly surprising since it was based on the idea there might be a ``compassion for animals'' linear representation which seems unlikely.\footnote{In fact, the steered model unrelatedly started talking about zoos so it had become somewhat obsessed with animals which could cut both ways.} I mostly wanted to try it because I thought it was a cheaper approach than SDF.
  \item \textbf{Prompting (almost definitively) works well in large models.} Although prompting didn't work well for the small models due to high rates of topic intrusion, the eval runs on Kimi points towards topic intrustion not being much of an issue as the model size scales while still leading to massive jumps in their ANIMA score.
\end{enumerate}

Given these results, I'm now less excited about technical alignment work for animals since it doesn't seem like a particularly hard problem given that a minimal change to a system prompt can lead to big effects. The crux of the matter seems to be a governance issue and I'm thus more excited about work such as \citetitle{moret2026animalwelfare} \cite{moret2026animalwelfare}. It seems that alignment work makes sense mostly as a marketing tool for governance.

\subsection{Limitations}

There are a few too many things I wished I had the time to tackle:

\begin{enumerate}
\item \textbf{Control for capabilities}. Although I control for topic intrusion, I didn't check for something more fundamental: are capabilities preserved?
\item \textbf{SDF on Llama-3.1-8B}. Although generally I think I should have used newer models (I regret not using Qwen 3.8–27B instead of Qwen3-32B), I would have liked to run SDF on Llama-3.1-8B in order to isolate the effect of using the competition's dataset.
\item \textbf{SDF with generic-data mix}. Due to budget constraints, I wasn't able to do this but I think this would have been a better way to do the fine-tuning.
\item \textbf{Better evals}. I'm not the biggest fan of the two animal-welfare evals I used for several reasons:

\begin{enumerate}
  \item They are quite small. TAC has only 13 scenarios and ANIMA only 115 questions.
  \item Some of the questions are not clear-cut in terms of their welfare impact. For example, the eval penalizes booking a trip to swim with dolphins but I don't think we have any welfare studies comparing the quality of life between wild dolphins and those in captivity. In general, animal welfare research is slim so I think evals should account for that.
\end{enumerate}

Another issue, not with the evals themselves but my use of them, was using Gemini 2.5 Flash-Lite as a judge. I would have liked to use a more capable model and re-run the evaluations from \textit{Alignment midtraining for animals} using this bigger model.

\end{enumerate}
